TANI CERDAS — WEBSITE DEMO DENGAN LOGIN

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder tani_cerdas_login.
3. Klik dua kali index.html untuk membukanya di browser.

FITUR
- Halaman beranda, fitur, komoditas, About Us, kontak, footer.
- Form masuk dan pendaftaran akun demo.
- Dashboard pengguna.
- Kalkulator kebutuhan pupuk berdasarkan luas lahan, dosis hara/ha, dan kadar hara produk.
- Kalkulator persentase perkecambahan.
- Catatan budidaya.
- Pengaturan jenis huruf, ukuran teks, tema, dan pengurangan animasi.

PENTING TENTANG KEAMANAN
Ini adalah prototipe frontend untuk demonstrasi. Akun baru dan catatan disimpan di penyimpanan browser (localStorage), dan kata sandi akun demo yang didaftarkan tidak dilindungi seperti sistem produksi. Jangan gunakan kata sandi asli atau data pribadi penting.
Fitur login ini BELUM aman untuk dipublikasikan atau digunakan untuk data nyata. Untuk penggunaan sungguhan, hubungkan ke backend autentikasi dan database (misalnya Supabase/Firebase) dengan penyimpanan kata sandi yang aman, aturan akses, verifikasi email, dan pemulihan kata sandi.
Kalkulator pupuk hanya alat bantu matematika. Gunakan dosis berdasarkan analisis tanah dan rekomendasi penyuluh/ahli setempat; jangan menganggap satu dosis berlaku untuk semua komoditas dan lahan.
